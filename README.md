# Sub Arc Calc

Calculator for the spacing and delays of an arc subwoofer line.

Enter the number of boxes, box width, line length, arc angle, temperature, humidity and edge margin. The page calculates:

- box spacing
- arc radius
- centre-to-centre length
- speed of sound
- position, gap, virtual distance, delay and normalized delay for every box

Tap the **i** next to a value to see a short explanation of what it is.

Venue and setup names can be saved and loaded again. On this site they are stored in your browser only.

It is a single static page (`index.html`) with no build step. Open it in a browser, or serve it with GitHub Pages.

The page has an app icon and a web app manifest, so it can be added to a phone's home screen or installed on a PC from the browser.
